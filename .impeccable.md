# Pathdle Design Context

## Users

Casual puzzle players (Wordle-adjacent). Short daily session: open → explore constellation → discover path → compare to optimal. Often on phone or laptop in a spare few minutes.

## Brand personality

**Mysterious · Cartographic · Crisp**

Feels like charting an unknown night sky of knowledge — curious and a little conspiratorial, not cute, not corporate SaaS.

## Aesthetic direction

- **Tone:** near-black night void — gold lamp START/score, teal TARGET/hints, lamp-ivory focus.
- **Metaphor:** knowledge constellation is the hero; HUD is a set of floating instrument plates, not an app chrome frame.
- **Layout:** full-bleed SVG playfield. **No** permanent side panels or card frames around the board.
- **Top HUD (one row, matched heights):** brand + How to play | **charted path rail** (flex, hops centered) | Score / Links. Same instrument padding/stretch.
- **Camera:** bottom-right `+` / `−` / recenter. Wheel zoom + pinch; drag empty sky to pan.
- **Typography:** Fraunces (display / brand / score) + Source Sans 3 (UI / in-node labels).
- **Color tokens (`globals.css`):** `--field-void` near-black; amber `--accent`; teal `--target` / `--hint`; `--focus` ivory; muted gray-blue unexplored.
- **Nodes:** large **pill bodies with labels inside** (wrapped title). START / TARGET tagged on the pill. Hover only highlights the pill (scale/stroke) — no floating label chips or leader lines.
- **Display layout:** API `(x,y)` kept as direction only; presentation spreads nodes onto a **wide circular ring** (START inward, TARGET outer) with collision push so pills do not overlap. Display-only — does not change published puzzle coordinates.
- **Edges:** path taken = solid amber (draw-on + faint flow); confirmed branch = solid muted gold; hints = dashed teal. Selection dims unrelated stars/edges (focus lamp).
- **Chart note:** click a star → floating note (desktop popover / mobile bottom sheet) with known neighbors + Reveal hints. Confirming a link is still **drag**.
- **Win:** reaching TARGET auto-opens results (efficiency, score breakdown, path chips, share). Keep charting dismisses the overlay.
- **Motion (restrained):** soft halo breathe on START/TARGET; successful edges draw ~0.5s; fail burst fades; score bump. Respect `prefers-reduced-motion`.
- **Background:** near-black void + subtle gold/teal/rose nebulae + sparse colored pinprick stars (client-mounted) + light grain — night atlas, not neon sci-fi dashboard.

## Anti-references

- Generic force-directed “developer graph” (D3 demo aesthetic)
- Bulky left/right chrome panels that trap the graph in an app frame
- Floating label chips / callouts that collide over the board
- Purple/indigo AI landing pages
- Cyan-glow dark “AI dashboard”
- Constant particle spam or continuous physics simulation
- Wordle clone UI with gray/green/yellow squares as the whole brand
- Card soup around the playfield

## Accessibility

- Keyboard: focusable nodes where practical; visible focus rings
- Contrast: in-node titles readable on dark pills over the void
- Reduced motion: disable float / draw / twinkle / pan flourish when requested
