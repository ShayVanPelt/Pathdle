# Pathdle Design Context

## Users

Casual puzzle players (Wordle-adjacent). Short daily session: open → explore constellation → discover path → compare to optimal. Often on phone or laptop in a spare few minutes.

## Brand personality

**Mysterious · Cartographic · Crisp**

Feels like charting an unknown night sky of knowledge — curious and a little conspiratorial, not cute, not corporate SaaS.

## Aesthetic direction

- **Tone:** observatory / night atlas — deep navy-black field, warm amber lamp accent, cool teal target marker.
- **Metaphor:** the living knowledge graph is the hero; chrome (HUD) floats quietly at the edges of the viewport.
- **Layout:** full-bleed playfield. No side panels, no card frames around the board. HUD overlays corners only.
- **Typography:** Fraunces (display / brand / score) + Source Sans 3 (UI / node labels).
- **Color:** deep blue-ink field (`oklch` ~250 hue); amber START/score; teal TARGET/hints; restrained soft glows — not neon spam.
- **Nodes:** small glowing cores with soft halos (not large beige discs). START/TARGET slightly larger with distinct markers.
- **Motion (restrained):** unconnected nodes drift ~1–2px on long CSS loops with staggered phases; connected nodes settle. Successful edges draw on (~0.5s); failed lines fade quickly. Score eases on change. Respect `prefers-reduced-motion`.
- **Background:** radial depth + sparse pinprick particles + light grain — sophisticated atmosphere, not a generic starfield or sci-fi dashboard.

## Anti-references

- Generic force-directed “developer graph” (D3 demo aesthetic)
- Bulky left/right chrome panels that trap the graph in an app frame
- Purple/indigo AI landing pages
- Cyan-glow dark “AI dashboard”
- Constant particle spam or physics simulation
- Wordle clone UI with gray/green/yellow squares as the whole brand
- Card soup around the playfield

## Accessibility

- Keyboard: focusable nodes where practical; visible focus rings
- Contrast: node labels readable on the field
- Reduced motion: disable float / draw / pan flourish when requested
